4. Keamanan & Penyimpanan

Keamanan data adalah prioritas kami. Kami menggunakan infrastruktur Google Firebase:

  • Semua data dikirim melalui koneksi terenkripsi TLS/HTTPS.
  • Database Firebase Firestore memakai aturan akses ketat sesuai peran pengguna.
  • Firebase Authentication tidak menyimpan kata sandi dalam bentuk teks biasa.
  • Server berada di Asia Tenggara (region asia-southeast1) dengan backup otomatis.

Google Firebase mematuhi standar ISO 27001, SOC 1/2/3, dan regulasi perlindungan data internasional.

Kami tidak menjual data pribadi Anda kepada pihak mana pun. Data hanya dibagikan dalam kondisi terbatas berikut:
